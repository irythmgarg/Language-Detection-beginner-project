# Language-Detection-beginner-project

# 🌍 Language Detection Project

This project is a machine learning application that detects the language of a given text input. The model is trained on a balanced dataset of 22 languages using a Naive Bayes classifier.

---

## 📊 Dataset Overview

The dataset consists of **22 languages**, each represented by **1,000 text samples**, resulting in a total of **22,000 samples**. Each sample contains a short script or sentence in the respective language. This makes the dataset perfectly balanced for training a language classification model.

### 📙 Supported Languages
- Estonian
- Swedish
- Thai
- Tamil
- Dutch
- Japanese
- Turkish
- Latin
- Urdu
- Indonesian
- Portuguese
- French
- Chinese
- Korean
- Hindi
- Spanish
- Pashto
- Persian
- Romanian
- Russian
- English
- Arabic

---

## 🧠 Technologies Used

- **Python**: Core programming language
- **Scikit-learn**: Model training using Multinomial Naive Bayes
- **CountVectorizer**: To convert text into numerical form
- **Streamlit**: For creating the interactive interface
- **Pickle**: For saving and loading the trained model and vectorizer

---

## 🚀 Features

- Real-time language detection from user input
- Covers 22 widely spoken and diverse languages
- Trained model is pre-loaded for fast predictions
- Clean and minimal user interface
